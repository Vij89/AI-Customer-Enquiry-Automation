# AI-Powered Customer Enquiry Automation

## Project Overview
Built an AI-powered business workflow automation using Activepieces, Google Sheets, Groq API and Gmail.

## Workflow
1. Capture customer enquiries from Google Sheets.
2. Analyse enquiries using Groq LLM.
3. Classify enquiry category and priority.
4. Generate customer intent and recommended actions.
5. Send automated email notifications through Gmail.

## Technologies Used
- Activepieces
- Google Sheets
- Groq API
- HTTP REST API
- JSON
- Gmail

## Business Benefits
- Reduces manual enquiry analysis.
- Automates email notifications.
- Improves enquiry prioritisation.
- Supports faster sales-team follow-up.

Successfully tested and deployed.
